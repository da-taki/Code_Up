# Security

CodeUp is a learning prototype for beginner Python education and demo use. Please do not use it as a general-purpose online judge, production sandbox, or place to run untrusted programs from unknown users.

## Reporting

If you find a security issue, please open a private report through GitHub security advisories if available, or contact the repository owner directly with:

- a short description of the issue
- steps to reproduce it
- expected impact
- any relevant environment details

Please do not publish exploit details before the issue has been reviewed.

## Demo Safety

CodeUp runs learner Python through the repository's sandboxed execution flow, but demos should still use small beginner programs only. Avoid secrets, credentials, personal data, destructive file operations, network probes, or code from untrusted sources.

Optional AI and Intel integrations are configuration-dependent and are not required for the core demo.
