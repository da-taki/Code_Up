# Accessible coding pathway

## CodeUp's role

CodeUp is a Python-focused, audio-first bridge for visually impaired beginners. It teaches code structure, output, errors, tracing, and project basics before a learner moves to a professional editor.

## Suggested progression

1. Complete the 12 CodeUp learning-path lessons.
2. Use Audio Blocks Mode when structured numbered blocks are more approachable than typing full Python.
3. Compile blocks into real Python and compare their structure with Code Mode.
4. Practice line order and indentation with accessible Parsons block practice.
5. Use error practice, request-only hints, code maps, and step narration.
6. Learn descriptive naming, short functions, keyboard navigation, and screen-reader-compatible project habits.
7. Export a project and continue in VS Code with screen reader mode and the learner's usual assistive technology.

## Related tools

Quorum is an accessible, evidence-oriented programming language and learning ecosystem. It is separate from CodeUp. CodeUp does not replace Quorum and has no claimed partnership or endorsement.

NVDA, JAWS, Windows Narrator, VoiceOver, and Orca provide operating-system and application access. CodeUp does not replace them. Braille displays continue to work through the learner's established screen-reader and platform workflow, subject to platform testing.

VS Code is the intended next step for larger mainstream Python projects. CodeUp export includes handoff notes and VS Code accessibility settings, but learners should still configure and test their own editor, extensions, terminal, screen reader, and Braille workflow.
