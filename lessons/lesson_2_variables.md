# Lesson 2: Variables

Goal: store information in a variable, then use it.

## Code

```python
name = "Asha"
subject = "Python"
print(name)
print(subject)
```

## Voice Commands

- Say `run`.
- Say `list variables`.
- Say `read line two`.

## Listen For

- CodeUp should speak the two printed values.
- Variable listing should tell you the current names and values after execution.

## Practice

Change `name` and `subject`. Run again and ask `what changed`.
