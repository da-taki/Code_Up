Accessible coding tools and pathways

CodeUp's role

CodeUp is a Python-focused, audio-first beginner bridge. It helps visually impaired beginners learn Python and prepare to move into professional tools such as Visual Studio Code.

CodeUp does not replace a screen reader, Braille workflow, professional editor, or another accessible programming environment.

Quorum

Quorum is an accessible, evidence-oriented programming language and learning ecosystem. CodeUp does not replace Quorum. CodeUp focuses on mainstream Python and the transition to VS Code.

Screen readers

CodeUp is designed for workflows that may use NVDA, JAWS, Windows Narrator, VoiceOver, or Orca. Behavior varies by operating system, browser, and assistive technology, and requires testing with real users.

Professional editor pathway

VS Code has a screen reader mode. CodeUp can export Python projects with handoff notes and accessibility settings so a learner can continue in VS Code with their usual assistive technology.

Suggested pathway

  1. Start with CodeUp lessons and audio debugging.
  2. Learn screen-reader-compatible coding habits.
  3. Explore Quorum as another accessible programming environment if useful.
  4. Move to VS Code for larger projects.
