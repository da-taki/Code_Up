# Lesson 3: Loops

Goal: understand repeated work and indentation through speech, trace, and sound.

## Code

```python
total = 0
for number in range(3):
    total = total + number
    print(total)
```

## Voice Commands

- Say `run`.
- Say `sonify block`.
- Say `next step`.
- Say `previous step`.
- Say `where am i`.

## Listen For

- The indented lines should sound different from the first line.
- The trace should explain how `total` changes.

## Practice Error

Delete the four spaces before `print(total)` and run again. Ask CodeUp to `explain simply`, then add the spaces back.
