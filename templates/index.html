More about CodeUp

CodeUp is a voice-first place to learn Python basics, in English. It works alongside your screen reader and headphones. It does not replace NVDA, JAWS, Braille, or VS Code. Put on headphones or turn on your speaker, and allow the microphone if you want to talk. If voice does not work, just type the command in the box and press Enter.

    Keyboard shortcuts

    • Ctrl+Enter — Run your code
    • Jump to editor skip link, or Tab from the top of the page — Focus the editor
    • Escape (editor quiet) or Ctrl+M — Leave the editor
    • Escape (while speaking) — Stop speech
    • Jump to command input skip link — Focus the command box
    • Jump to output skip link — Focus program output
    • Ctrl+Shift+M — Toggle CodeUp Voice control
    • Alt+Shift+O — Open accessibility and speech settings
    • Alt+Shift+K — Open this shortcut list
    • Ctrl+Shift+P — Command palette
    • In Audio Blocks: Ctrl+Enter compile, Ctrl+Shift+Enter run, arrow keys move between blocks, [ / ] outdent / indent

    Getting started with CodeUp

    1. Use the Jump to editor skip link, or Tab from the top of the page, to reach the code editor.
    2. Type Python code in the editor. Tab moves focus out, so use Ctrl+] / Ctrl+[ to indent and outdent.
    3. Press Ctrl+Enter, or the Run button, to run your code.
    4. Use the Jump to output skip link to inspect the program output.
    5. Use the Jump to command input skip link, or the Commands box, to type or say a command.
    6. Say or type "read last error" to hear and explore any error in detail.
    7. In Screen Reader Safe mode, CodeUp stays quiet and lets NVDA, JAWS, VoiceOver, or Narrator read everything.
    8. Switch to CodeUp Voice in the display and accessibility settings if you want CodeUp to narrate automatically.
    9. Press Alt+Shift+K any time for the full keyboard shortcut list.
    10. Press Escape (or Ctrl+M) to leave the editor when you are done typing.
    11. Use the Classroom and Instructor tools links at the top of the page for classroom features.
