# Lesson 1: Print

Goal: write and run a first Python program without using a mouse.

## Start

1. Open the IDE.
2. Press `Tab` until the editor is focused, or ask the teacher to place focus there.
3. Type:

```python
print("Hello, CodeUp")
```

## Voice Commands

- Say `run`.
- Say `read output`.
- Say `help` if you forget a command.

## Listen For

- The program output should be spoken.
- The output panel should contain `Hello, CodeUp`.

## Practice

Change the message to your name, your class, or your favorite subject. Run again and listen for the changed output.
